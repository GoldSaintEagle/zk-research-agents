# Post-quantum and hash-based zero knowledge

Zero-knowledge proofs believed to resist quantum adversaries: MPC-in-the-head (IKOS07, ZKBoo, KKW18, Limbo, threshold computation in the head) and the signatures built on it (Picnic, Banquet, SDitH, VOLE-in-the-head/FAEST), hash-based IOP SNARKs (Ligero, Aurora, STARK, Orion, Brakedown, Basefold, Blaze), lattice-based succinct arguments (LaBRADOR, Greyhound), and the quantum security of the compilers (Micali/BCS in the QROM, Fiat-Shamir in the QROM). Lyu12 is kept as the Fiat-Shamir-with-aborts reference point for lattice signatures. This list absorbs the ZK-relevant part of the former post-quantum signatures list. ZKBoo (USENIX Security 2016) is left out because no DOI could be verified for it; KKW18 and later MPCitH papers supersede it in practice. Entries partly drawn from the bibliographic notes of [CY24 §Bibliographic notes, section:bibliographic-notes].

Suggested order: IKOS07 -> GMO16 -> KKW18 -> CDGORRSZ17 -> BDKOSZ21 -> DOT21 -> FJR22 -> FR25 (MPC-in-the-head, signatures); BBDKORS23 (VOLE-in-the-head); AHIV23 [in pcs] -> BCRSVW19 [in piop-arithmetization] -> BBHR19 [in piop-arithmetization] -> XZS22 -> GLSTW23 [in pcs] -> ZCF24 [in pcs] -> BCFRRZ25 [in pcs] (hash-based SNARKs); Lyu12 -> BS23 -> NS24 (lattices); DFMS19 -> CMS19 (quantum security of the compilers).
